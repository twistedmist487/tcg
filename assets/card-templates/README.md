# Card templates

Style boards from the uploaded reference sheet, plus isolated fronts/backs and an HTML frame.

## Isolated cards (use these)

| Front | Back |
|---|---|
| `fronts/illuminati-front.jpg` | `backs/illuminati-back.jpg` |
| `fronts/templars-front.jpg` | `backs/templars-back.jpg` |
| `fronts/reptilians-front.jpg` | `backs/reptilians-back.jpg` |
| `fronts/network-front.jpg` | `backs/network-back.jpg` |

Each front is 378×592. Each back is 374×592. Same layout, faction-tinted.

## Source sheets

| File | What |
|---|---|
| `illuminati-sheet.jpg` | Full board: front + back + emblem coins |
| `templars-sheet.jpg` | Full board |
| `reptilians-sheet.jpg` | Full board |
| `network-sheet.jpg` | Full board |
| `preview.html` | HTML/CSS frames with real text slots |

The sheets are art direction. Names, costs, and rules belong in `preview.html` or the live UI, not in the JPEGs.
